**今天只做一件可见的事**

在仓库根目录使用原有虚拟环境运行：

```powershell
.\.venv\Scripts\python.exe projects/fashion-classifier/inspect_data.py --download
```

工具读取公开 Fashion-MNIST 训练数据，显示一批图像张量的形状，并保存 16 张样本预览至 `runs/data_preview.png`。工具代码由助手提供，运行成功不计为独立实现模型。数据读取的压缩格式不是本阶段的学习重点。

解释输出中的 `(32, 1, 28, 28)` 四个数字分别代表什么；说明输入和标签的对应关系。随后在这个项目中练 Dataset／DataLoader、分类器、损失、训练与验证。

当前仓库 `.venv` 已有 CPU 版 PyTorch、NumPy 与 Matplotlib；该工具不依赖尚未安装的 torchvision。使用既有环境，避免误用系统 Python。首次需要网络下载公开训练数据，缓存已有则不重复下载。

**七次学习的成果**

| 次序 | 核心任务 | 当次可展示的证据 |
|---|---|---|
| 1 | 读图、看标签、理解 batch | 数据预览与张量形状解释 |
| 2 | 从官方训练部分固定抽样并分 train／val，构造数据加载 | 例如 5,000 条训练、1,000 条验证的固定索引；无重叠检查 |
| 3 | 用 Flatten＋Linear 建立最简单分类器，理解 logits 与交叉熵 | 一次前向的输入／输出形状、一次参数更新 |
| 4 | 完成训练与验证，验证不更新参数 | 训练／验证曲线和验证准确率 |
| 5 | 只改变一项设置，比如学习率或隐藏层，做对照 | 同一划分、同一预算下的比较表 |
| 6 | 保存、加载、预测，并查看错分图片 | 错分样本图与错误类型说明 |
| 7 | 关闭参考，自主重写关键训练流程并讲解 | 独立验收结果和最薄弱的一项 |

先使用固定小子集控制 CPU 时间；未达到理想准确率时按数据、形状、损失和优化排查，不靠不断换模型。官方测试集留作最终检查，不作为日常调参集。任何第一次看到的输出，都不能提前填入进度。

**怎么判断升级了**

- 跟着完成：能运行给定示例，解释主要输入输出。
- 独立实现：只查 API 文档，能自己写核心训练与评估流程。
- 排错分析：能定位至少一个真实故障，用对照实验解释结果。
- 完整项目：别人可按说明复现，能解释数据、指标、错误与限制。

本周主要争取前两项，第三项有真实证据再记录。每次学习只记录实际实现的部分、使用了哪些提示、下一处卡点；不用写长篇日志。
