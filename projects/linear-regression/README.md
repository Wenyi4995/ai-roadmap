# 线性回归项目

## 问题与目标

使用模拟数据 `y = 3x + 2 + noise` 理解前向传播、MSE、自动求导和参数更新，并比较手动实现与 PyTorch 标准实现。

成功标准：

- 两种实现都能够运行；
- 学习到的权重和偏置接近 3 和 2；
- Loss 随训练整体下降；
- 能够解释每一个训练步骤。

## 实现

1. `train_manual.py`：手动定义参数和梯度更新。
2. `train_pytorch.py`：使用 `nn.Linear` 与 `torch.optim.SGD`。
3. 完成后增加 Loss 曲线和拟合结果图。

## 验收问题

- 前向传播是什么？
- MSE 衡量了什么？
- `loss.backward()` 做了什么？
- 为什么每轮需要清空梯度？
- 学习率过大或过小分别会怎样？
- 最终权重和偏置为什么不一定严格等于 3 和 2？

## 实验记录

| 实现 | 学习率 | 训练轮数 | 最终 Loss | 权重 | 偏置 |
|---|---:|---:|---:|---:|---:|
| 手动实现 | 0.005 | 1000 | 0.038516 | 2.9970 | 2.0119 |
| PyTorch 标准实现 | 0.005 | 1000 | 2.72e-09 | 3.0000 | 1.9999 |

两种实现使用的数据不同：手动版包含随机噪声，标准版使用无噪声数据，因此不能仅凭最终 Loss 判断哪种实现更好。学习率从 0.01 降至 0.005 后，两种实现都收敛得更慢，但最终仍能接近目标参数。
