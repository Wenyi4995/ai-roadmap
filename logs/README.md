# Logs

日志分为两层：

1. 每日记录按真实日期保存为 `logs/YYYY/MM/YYYY-MM-DD.md`。
2. 周复盘保留为 `logs/YYYY/MM/week-NN.md`，只汇总成果和调整，不使用 `Day 1`、`Day 2` 代替真实日期。

每日记录实际开始时间、结束时间、有效学习时长、产出、障碍和下一步。没有可靠记录的数据填写“未记录”，不根据对话长度猜测。

建议使用方式：

- 开始学习时说“今天开始”，记录开始时间和唯一任务。
- 学习过程中不必频繁修改日志。
- 结束时说“今天结束”，根据实际文件和对话精炼记录结束时间、成果与下一步。
- 中断后另一天继续，直接创建新的日期文件，不补写成连续的 Day 编号。

知识解释保存在 `learning/`，项目实验保存在项目 README；日志只记录当天事实和证据链接。
