## 当前任务

从 [第一周学习计划](week01/README.md) 开始，每天完成最低专注任务并提交学习记录。

## 每日工作流

1. 开始前把手机移出桌面。
2. 阅读当天任务，只选择一个最小动作。
3. 完成 25 分钟专注块。
4. 运行代码并记录结果。
5. 更新打卡表和每日记录。
6. 使用清晰的提交信息保存成果。

推荐提交信息：

```text
study: finish day 1 Python review
code: implement autograd exercise
docs: add week 1 reflection
```
